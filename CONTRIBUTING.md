# Contributing

## Before You Start
- Read `AGENTS.md`.
- Understand the current architecture before changing it.
- Confirm the project's package manager and available scripts from the repository.

## Development
- Keep changes focused.
- Follow existing conventions.
- Reuse existing utilities and dependencies.
- Add tests for meaningful behavior changes.
- Update documentation when developer-facing behavior changes.

## Validation
Run the relevant commands defined by the project:
- formatting/linting
- type checking
- targeted tests
- full tests when practical
- production build when relevant

Do not report a check as passing unless it was actually executed.

## Pull Requests
Include:
- problem and intended outcome;
- summary of implementation;
- validation performed;
- risks/limitations;
- screenshots or API examples when relevant.

Keep pull requests focused and avoid unrelated cleanup.
